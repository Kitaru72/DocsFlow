DocsFlow - Python-приложение для генерации DOCX-документов по шаблонам и структурированным данным.

Первый сценарий использования - автоматизация подготовки отчетов по лабораторным работам.

## Цели проекта

- Закрепить базовый Python на практическом проекте.
- Научиться работать с файлами, JSON и структурой проекта.
- Постепенно развить CLI-приложение в backend-сервис на FastAPI.
- Подготовить проект для портфолио.

## План развития

- CLI-версия для создания профилей и отчетов.
- Генерация DOCX-документов.
- REST API на FastAPI.
- Хранение данных в PostgreSQL.
- Docker и деплой на сервер.
