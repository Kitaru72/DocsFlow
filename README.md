# DocsFlow

DocsFlow - консольное Python-приложение для подготовки данных лабораторного отчета и генерации DOCX-документа.

Проект начался как учебная автоматизация оформления лабораторных работ, но постепенно развивается в полноценный инструмент для работы с профилями, данными отчетов, JSON-хранилищем и генерацией документов.

## Текущий статус

Сейчас реализована CLI-версия приложения с меню. Пользователь может создавать и загружать профили, создавать и загружать данные отчета, а затем генерировать DOCX-отчет на основе выбранных данных.

## Возможности

- CLI-меню для выбора действий.
- Создание профиля через консоль.
- Загрузка сохраненного профиля из списка.
- Создание данных лабораторного отчета:
  - дисциплина;
  - номер лабораторной работы;
  - тема;
  - список заданий.
- Загрузка сохраненных данных отчета из списка.
- Нормализация строковых данных: удаление лишних пробелов.
- Валидация обязательных полей.
- Безопасный ввод положительного числа для количества заданий.
- Форматированный вывод профиля и данных отчета в консоль.
- Сохранение профилей в JSON.
- Сохранение данных отчетов в JSON.
- Поиск JSON-файлов в директориях профилей и отчетов.
- Обработка отсутствующих и некорректных JSON-файлов.
- Объединение профиля и данных отчета в структуру для генерации документа.
- Генерация DOCX-отчета через `python-docx`.
- Уникальное имя DOCX-файла на основе профиля и номера лабораторной работы.

## Назначение модулей

`main.py` - точка входа в приложение. Запускает CLI-интерфейс.

`app/cli.py` - консольный интерфейс и пользовательские сценарии: создание профиля, загрузка данных, выбор файлов, генерация DOCX.

`app/profiles.py` - логика профилей: создание, валидация и форматирование.

`app/reports.py` - логика данных отчета: создание, валидация и форматирование.

`app/storage.py` - работа с JSON-файлами, путями и поиском сохраненных данных.

`app/docx_generator.py` - объединение данных и генерация DOCX-документа.

## Установка и запуск

Проект использует `uv` для управления окружением и зависимостями.

Установить зависимости:

```powershell
uv sync
```

Запустить приложение:

```powershell
uv run python main.py
```

## CLI-меню

```text
1. Создать профиль
2. Загрузить профиль
3. Создать данные отчета
4. Загрузить данные отчета
5. Сгенерировать DOCX-отчет
0. Выйти
```

## Где хранятся данные

Профили сохраняются в:

```text
data/profiles/
```

Данные отчетов сохраняются в:

```text
data/reports/
```

Сгенерированные DOCX-файлы сохраняются в:

```text
output/
```

Сгенерированные JSON и DOCX-файлы не добавляются в Git, потому что это пользовательские данные и результаты работы программы.
