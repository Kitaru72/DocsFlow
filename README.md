# DocsFlow

DocsFlow - консольное Python-приложение для подготовки данных лабораторного отчета и генерации DOCX-документа.

Проект начался как автоматизация подготовки учебных отчетов, но постепенно развивается как небольшой инструмент для работы со структурированными данными, JSON-хранением и генерацией документов.

## Текущий статус

Сейчас реализована CLI-версия приложения. Пользователь вводит данные студента и лабораторной работы через консоль, приложение проверяет данные, сохраняет их в JSON и генерирует DOCX-отчет.

## Возможности

- Ввод профиля студента через консоль.
- Ввод данных лабораторной работы:
  - дисциплина;
  - номер лабораторной работы;
  - тема;
  - список заданий.
- Нормализация строковых данных: удаление лишних пробелов.
- Валидация обязательных полей.
- Безопасный ввод положительного числа для количества заданий.
- Форматированный вывод профиля и отчета в консоль.
- Сохранение профиля студента в JSON.
- Загрузка профиля студента из JSON.
- Сохранение данных отчета в JSON.
- Загрузка данных отчета из JSON.
- Обработка отсутствующих и некорректных JSON-файлов.
- Объединение данных студента и отчета в одну структуру для генерации документа.
- Генерация DOCX-отчета через `python-docx`.

## Назначение модулей

- `main.py` - точка входа и основной CLI-сценарий приложения.
- `app/cli.py` - функции для безопасного консольного ввода.
- `app/profiles.py` - создание, валидация и форматирование профиля студента.
- `app/reports.py` - создание, валидация и форматирование данных отчета.
- `app/storage.py` - универсальное сохранение и загрузка JSON, а также функции для профиля и отчета.
- `app/docx_generator.py` - объединение данных и генерация DOCX-документа.

## Файлы конфигурации

- `pyproject.toml` - конфигурация Python-проекта и список зависимостей.
- `uv.lock` - зафиксированные версии зависимостей для воспроизводимой установки.
- `.python-version` - версия Python, используемая проектом.
- `.gitignore` - исключения для Git: виртуальное окружение, кэш, локальные настройки, JSON-данные и сгенерированные DOCX-файлы.

## Установка и запуск

Проект использует `uv` для управления зависимостями и виртуальным окружением.

Установить зависимости:

```powershell
uv sync
```

Запустить приложение:

```powershell
uv run python main.py
```

## Результат работы

После успешного запуска приложение создает локальные файлы:

```text
data/profile.json
data/report.json
output/student_report.docx
```

Эти файлы не коммитятся в репозиторий, потому что содержат пользовательские данные и сгенерированный результат.
