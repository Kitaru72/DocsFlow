# DocsFlow

DocsFlow - Python-приложение для подготовки и генерации DOCX-документов на основе структурированных данных.

Первый сценарий использования - автоматизация подготовки отчетов по лабораторным работам.

## Текущий статус

Сейчас реализована базовая CLI-логика для работы с профилем студента.

## Возможности

- Ввод данных профиля студента через консоль.
- Нормализация данных: удаление лишних пробелов.
- Валидация обязательных полей.
- Красивый вывод профиля в консоль.
- Сохранение профиля в JSON.
- Загрузка профиля из JSON.
- Обработка отсутствующего или некорректного JSON-файла.
